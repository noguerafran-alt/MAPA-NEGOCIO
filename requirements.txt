# La capa de proyeccion (numpy + pandas + lightgbm) NO se instala aca a proposito.
#
# Importarlas cuesta 141 MB de RSS y entrenar pica en 280 MB; la instancia tiene
# 512 MB contando Flask, el historico 2001-2022 y el JSON de /api/data, asi que
# el modelo no entra en el proceso web. Ademas son ~12 s de CPU a un hilo, que
# con 0.5 CPU son 25-30 s en la primera visita despues de CADA reinicio, porque
# el cache del modelo vive en memoria y se pierde con el proceso.
#
# En su lugar el deploy sirve proyeccion_precomputada.json, que se genera con
# `python precomputar_proyeccion.py` en una maquina con RAM y se commitea. Para
# eso estan las dependencias del modelo, en requirements-modelo.txt.
